# 附录A　时间坐标与并行的历史

这张表用于定位阅读，不把朝代边界当作款式一夜改变的界线。服装常沿用前代，也在同一时期因地域、身份、职业和场合而不同。辽、宋、金等政权曾经并存，不应排成互相替代的单线。

| 阅读段落 | 大致时间 | 放在一起观察的问题 |
| --- | --- | --- |
| 先秦 | 秦统一以前，止于公元前221年 | 礼制叙述与楚地出土衣物怎样互证 |
| 秦 | 公元前221—前206年 | 俑像中的长衣、裤与劳动或官署身份 |
| 汉 | 通常列公元前206—公元220年，包含中间的政权变化 | 袍服、曲裾、直裾与轻薄丝织品 |
| 魏晋南北朝 | 220—589年这一多政权阶段 | 宽衣与窄袖并存，跨地域技术交流 |
| 隋唐五代 | 隋581—618；唐618—907；五代907—960年 | 高束裙、袍衫、带与靴；别忽视初晚期差别 |
| 两宋 | 960—1279年 | 女服实物、城市活动与礼仪图像 |
| 辽与金 | 辽常列916—1125；金1115—1234年 | 与宋并存；同一政权内部也有多种衣冠 |
| 元 | 1271—1368年 | 蒙古传统、汉地衣着与制度服装的互动 |
| 明 | 1368—1644年 | 衫袄、裙、袍衫与等级标识；时期差异 |
| 清 | 本表以1644年入关至1912年为阅读范围 | 制度变革、汉族女服延续、区域差异 |
| 近现代 | 19世纪晚期至20世纪 | 新材料、成衣产业、身体观与生活方式改变 |
| 当代 | 20世纪末至21世纪的相关实践 | 历史研究、社群重建、现代商品与日常穿着 |

汉代起点有以刘邦受封汉王的公元前206年计、有以称帝的公元前202年计；辽的年代在博物馆艺术分期中也常用907—1125年。书中引用具体藏品时保留该机构标注，不擅自把藏品年代改成另一种断代。这些差别提醒我们：政权建立、统一或入关的日期，并不是同一类界限。

年代坐标可交叉核对[华盛顿大学出版平台的简明年表](https://uw.manifoldapp.org/read/observing-the-unseen/section/c11329df-55a5-47d2-bda3-629ad4ce6e79)与[伯明翰大学中国史年表](https://artsweb.cal.bham.ac.uk/NStanden/mongols/chinachron.html)。服饰分期则参阅[中国国家博物馆“中国古代服饰文化”专题](https://www.chnmuseum.cn/portals/0/web/zt/202102gdfsh/)，并回到每章具体对象。

## 两条同时使用的阅读线

沿历史读第3—12章，可以看到衣着如何变化。沿结构读第2、13—20章，可以比较不同年代的人如何解决遮覆、固定、活动和装饰的问题。一件明代马面裙既属于一个时期，也属于围合裙结构、丝织技术与穿着场景；这几种位置不互相替代。

## 不把今天的名称投射到全部古代

本书以“汉服”作为当代读者熟悉的主题总名。写先秦与中古时，仍尽量说具体衣名、地区与证据，不假定古人一直用同一套现代分类称呼自己。辽金元及清宫比较材料的纳入，是为了理解关系与边界，不表示所有古代中国服装都被归入同一个衣着类别。
