# 附录B　衣冠观察词汇

这里提供的是阅读索引，不是跨越全部朝代的唯一词典。同一词在文献、馆藏目录与当代商品中可能指向不同对象；具体用法以相应章节所列材料为准。

| 词语 | 本书中的观察含义 | 继续阅读 |
| --- | --- | --- |
| 形制 | 衣物构成、连接、开合与围合的方式 | 第2、20章 |
| 廓形 | 穿着或展开时看见的总体轮廓 | 第2、5章 |
| 领 | 颈口及领缘构造 | 第2章 |
| 襟 | 前部衣片的开启与覆盖关系 | 第2章 |
| 交领 | 两侧领缘在前胸斜交 | 第2、14章 |
| 对襟 | 前开口两边相向的关系 | 第2、8章 |
| 右衽 | 向穿着者右侧交掩，左右以穿者为准 | 第2、23章 |
| 圆领 | 颈口的形状；还需另看衣襟开合 | 第7、14章 |
| 袖口 | 袖管末端的开口 | 第2章 |
| 通袖长 | 衣物展开后两袖端之间的测量值 | 第2、23章 |
| 衩 | 保留不缝合的开口，需要和接缝区分 | 第2、14章 |
| 摆 | 袍服研究中的特定侧部结构，需依对象理解 | 第11、14章 |
| 襌衣 | 无衬里的单层衣物；襌读dān | 第4、15章 |
| 夹衣 | 有面、里层的衣物 | 第15、17章 |
| 丝绵 | 由蚕丝形成的绵絮，不等于棉花 | 第4、17章 |
| 曲裾与直裾 | 用于讨论衣襟、下部构造与穿法的术语 | 第4章 |
| 深衣 | 古代文献中的服制名称，文本与出土对象需解释对读 | 第3、4章 |
| 襦、衫、袄 | 随时代与材料变化的上衣称谓，不能仅依字名定结构 | 第6、10章 |
| 半臂 | 文献、图像中涉及短袖上衣的称呼 | 第6章 |
| 帔帛 | 相关图像中的长条披绕织物 | 第6章 |
| 褙子、背子 | 需结合具体时期与实物说明的衣名 | 第8、21章 |
| 比甲 | 讨论明等时期无袖外层衣物时须核对的名称 | 第10章 |
| 道袍 | 明代日常袍服讨论与道教法衣语境不能混淆 | 第11、14章 |
| 曳撒、贴里 | 相关历史名称及当代结构分类存在对应争议 | 第11章 |
| 飞鱼 | 纹样及制度语境中的名称，不能直接充当唯一裁剪名称 | 第11、18章 |
| 裙门 | 裙身中相对平整、与褶区有别的部分 | 第13章 |
| 褶裥 | 收纳布量、形成容量或表面节奏的处理 | 第13章 |
| 马面裙 | 具体历史结构与当代商品都需进一步辨别的裙名 | 第10、12、13章 |
| 幞头 | 历史冠巾类别，其外形和制作随时期变化 | 第7、16章 |
| 履、靴 | 足衣称谓，具体构造需读实物与图像 | 第16章 |
| 经线、纬线 | 织造中相互交织的两组线 | 第17章 |
| 平纹、斜纹、缎纹 | 织物组织，不是纤维原料 | 第17章 |
| 纱与罗 | 需结合具体时代组织分析的轻薄丝织物称谓 | 第17章 |
| 织锦 | 图案与织造系统有关，不能等同全部刺绣 | 第17、18章 |
| 刺绣 | 在底料上另加绣线等形成装饰 | 第18章 |
| 缂丝 | 以特定经纬织造方式表现图像的工艺 | 第18章 |
| 绞缬 | 以扎结等形成防染效果的相关工艺 | 第5、18章 |
| 补子 | 特定时期与制度中的标识性织绣部件 | 第11、19章 |
| 复原 | 在证据与明确假设上提出、制作和修订的解释 | 第20章 |
| 当代汉服 | 今天由研究、社群、设计、商品和穿着共同构成的实践 | 第22章 |

词义与实例的出处见相应章节。初读时不必背下全表；遇到一件衣服，先记录看见的开合、接缝和长度，再查可能的名称。读者自己的未确定项也应保留在记录里。
