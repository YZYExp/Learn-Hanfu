# 衣冠之间：实穿参照增补标准

本轮目的：补足从平铺文物、文字和结构示意到身体上外观之间的阅读缺口，而不是用生成图证明历史。

- 图为照片级 AI 生成的成年现代模特穿着复原/试制衣物的教学展示。不能冒称历史照片、出土衣服原件、博物馆认证复原或真实人物。
- 统一柔和侧前光、灰米白背景、自然皮肤与布面、平视镜头、无美颜仙侠滤镜、无宫殿道具。人物 25–45 岁，表情中性，身体与手完整。全身图留出头顶与鞋底，衣领衣襟不可被头发或手挡住。
- 历史图每张有具体来源。一次只展示该文物/图像确实支持的领襟、袖形、长度或层次；发型、鞋、纹样、颜色、内层及背面无依据时简化，且图注明确它们不是已证实的细节。不能无来源拼出一套华丽衣服。
- 可生成成对/三视展示，但单张至多 3 面，重点充分可读。不要把几个不同历史对象揉成一件。精确裁片/系带/暗摆结构继续以可核验示意图承担。
- 每个成品须查看实际像素，按图注承诺检查。必要时修图，无法核实关键特征则剔除或降级用途，不靠文字掩饰明显错图。
- 图片内不生中文长标签，解释放图注。所有历史图图注包含：AI 生成的复原展示（非史料）；来源支持哪些特征；哪些项目为展示性补足/仍不确定。
- 配图按知识点分配，不固定每章数量。史料图和原版权说明保留；新增图与对应史料就近比较。

图像审校包括领襟方向、袖形、系带／扣数、前后与多视图一致性，以及图注是否超出具体来源。不能通过的版本不进入读者图片目录。
